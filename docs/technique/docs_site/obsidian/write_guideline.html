Obsidian 日文筆記排版與語法指南

本指南匯整在 Obsidian 中撰寫日文筆記所需的進階 Markdown 語法與排版技巧，包含振假名（標音）、註解、上標重音與單字對照排版。

1. 振假名標音 (Furigana / Ruby)​

原生 HTML 語法（支援 Quartz 網頁發布）​

不需要安裝任何外掛，原生 HTML <ruby> 語法可在 Obsidian 本機與發布後的 Quartz 網站完美渲染：

<ruby>私<rt>わたし</rt></ruby>は<ruby>日<rt>に</rt>本<rt>ほん</rt>語<rt>ご</rt></ruby>を<ruby>習<rt>なら</rt></ruby>っています。

外掛簡化寫法（搭配 Furigana Plugin）​

安裝 Furigana 外掛後，可用更直覺的語法寫作：

[私]{わたし}は[日本語]{にほんご}を[習]{なら}っています。

2. 上標與下標（音調重音 / 詞性標註）​

利用 HTML 的 <sup>（上標）與 <sub>（下標）來標示日文的音型（高低音）或詞性。

重音標號 (Accent Types)​

<!-- 標示 0 型音 (平板型) -->
水<sup>0</sup>（みず）

<!-- 標示 1 型音 (頭高型) -->
本<sup>①</sup>（ほん）

<!-- 標示高低音流向 -->
あ<sup>↑</sup>りがとう<sub>↓</sub>

詞性標註​

食べる<sub>（動詞・下一段）</sub>
きれい<sub>（形動）</sub>

3. 註解與腳註 (Footnotes & Callouts)​

適合用於解釋文法背景、文化差異或補充說明。

標準腳註 (Footnotes)​

文章中插入標號，於底端集中解釋：

這個句型常用於商業情境[^1]，一般朋友交談時較不常使用[^2]。

[^1]: 屬於敬語中的「謙譲語」，對上司或客戶使用。
[^2]: 口語中通常直接改用普通形。

行內即時註解 (Inline Footnotes)​

不用跑到文章底部，直接在句子中插入註解：

彼はツンデレ^[外冷內熱的性格，來源於「ツンツン」與「デレデレ」]な性格ですね。

強調註解卡片 (Callout Blocks)​

用 Obsidian 的 Callout 框標記重點文法陷阱：

> [!NOTE] 易錯提醒
> **～にあたって** 後面不能接表示「否定」或「過去」的文法。

4. 行與行對照解析（逐字翻譯與對應）​

當需要對日文句子的「上一行（原句）」與「下一行（逐字解釋/詞性）」進行精密對齊時，可採用以下三種排版方式：

方法 A：Markdown 無邊框表格（推薦，排版最整齊）​

將單詞拆解，上一行放置日文原句，下一行放置文法註解：

昨日は友達と映画を見に行きました
名詞+助詞名詞+助詞名詞+助詞動詞複合形
昨天（時間）與朋友（對象）電影（目的）去看了（動作）

方法 B：行內代碼塊對齊（適用於簡易對照）​

利用等寬字型（Monospace）進行空白對齊：

原句： 昨日は     友達と     映画を     見に行きました。
對照： [名+助]   [名+助]    [名+助]    [動詞連用形+去]
翻譯： 昨天       和朋友     電影       去看了

方法 C：對照式引用區塊（適合文章對譯）​

利用 Blockquote 的層級做出日文與中文的上下層對應：

> 昨日は友達と映画を見に行きました。
> — *昨天和朋友去看電影了。*
>> **解析：**
>> * **昨日（きのう）**：名詞，昨天。
>> * **は**：提示主題助詞。
>> * **と**：表示共同動作的對象（和...）。

5. 綜合筆記實戰範例​

一份結構完整且排版優雅的 Obsidian 日文筆記示範：

---
title: ～ことにしている
tags:
  - 日文/N3文法
  - 習慣
aliases:
  - kotoni shite iru
---

# ～ことにしている

### 意思
表示**個人習慣或主觀決定的習慣**（每天、定期做的事）。

### 結構
> **動詞辭書形 / 動詞ナイ形** ＋ ことにしている

---

### 例句對照與解析

| 毎日 | <ruby>朝<rt>あさ</rt></ruby> | 6時に | <ruby>起<rt>お</rt></ruby>きる | ことにしている。 |
| :---: | :---: | :---: | :---: | :---: |
| 副詞 | 名詞 | 時間助詞 | 動詞原形 | 決定/習慣文法 |
| 每天 | 早上 | 在6點 | 起床 | 養成習慣 |

> 毎日朝6時に起きることにしている。
> <sub>（我堅持每天早上六點起床。）</sub>

[^注意]: 與「**～ことになっている**」不同，後者代表「規定、集體決定或客觀法律」。

> [!TIP] 記憶撇步
> * **している** = 主觀自己決定的動作。
> * **になっている** = 被背景或他人決定的規定。

``!!
