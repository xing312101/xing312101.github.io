Quartz + Obsidian 數位花園架設指南

本教學適用於希望建立個人知識庫（Digital Garden）或日文筆記網站的創作者。這套架構將 Obsidian 的本地純文字寫作體驗與 Quartz 4.0 的靜態網站生成能力相結合，既能維護資料的 100% 掌控權，又能免費發布至網路上。

核心架構說明​

┌────────────────┐     Git Push      ┌────────────────┐     Auto Build     ┌────────────────┐
│  Obsidian      ├──────────────────►│  GitHub Repo   ├──────────────────►│ Cloudflare     │
│  (本機 Markdown)│                   │  (私有/公開)   │                   │ (或 GitHub Pages│
└────────────────┘                   └────────────────┘                   └───────┬────────┘
                                                                                  │
                                                                           公開訪客瀏覽網站
  • Obsidian：本地端 Markdown 編輯器，負責資料儲存與日常寫作。
  • Quartz 4.0：專為 Obsidian 設計的靜態網站生成器（SSG），自動將雙向連結與標籤渲染成網站。
  • GitHub：託管網站原始碼與筆記檔案。
  • Cloudflare Pages / GitHub Pages：提供免費的全球 CDN 託管與自動化建置。

前置準備​

在開始前，請確保電腦已安裝以下軟體：

  1. Node.js (v18.14.0 或以上版本)
  2. Git 版本控制工具
  3. Obsidian 本地筆記軟體
  4. GitHub 帳號

第一步：建立與初始化 Quartz 專案​

1. Clone Quartz 倉庫​

開啟終端機（Terminal 或 PowerShell），執行以下指令複製 Quartz 官方儲存庫：

# 1. 將 Quartz 倉庫 Clone 到本機（請替換為你的目標資料夾名稱）
git clone [https://github.com/jackyzha0/quartz.git](https://github.com/jackyzha0/quartz.git) japanese-notes

# 2. 進入專案目錄
cd japanese-notes

# 3. 安裝依賴套件
npm ci

2. 初始化 Quartz 設定​

執行 Quartz 提供的互動式初始化工具：

npx quartz create

畫面上會出現選項選單，請依序選擇：

  • Choose how Quartz initialized: 選擇 Empty Quartz（建立乾淨空架構）。
  • Content location: 輸入你的 Obsidian Vault（儲存庫）路徑，或直接將筆記放入 content/ 資料夾。

第二步：配置 Obsidian 與內容管理​

Quartz 預設會讀取專案內 content/ 資料夾下的所有 Markdown 檔案。

推薦的專案目錄結構​

japanese-notes/
├── content/               <--- 所有 Markdown 筆記放在這裡
│   ├── index.md           <--- 網站首頁 (必須保留)
│   ├── 文法/
│   │   └── N3-動詞變形.md
│   └── 單字/
│       └── 常用副詞.md
├── quartz.config.ts       <--- 網站核心設定檔 (標題、主題顏色、外掛)
├── quartz.layout.ts       <--- 頁面版型佈局設定
└── package.json

必備的首頁檔 (content/index.md)​

建立 content/index.md 作為網站入口點：

---
title: 我的日文學習數位花園
---

# 歡迎來到我的日文筆記本 🌸

這裡記錄了我學習日文文法、單字與閱讀的個人筆記。

## 熱門主題
* [[文法/N3-動詞變形|N3 動詞變形總整理]]
* [[單字/常用副詞|必背 N3 副詞]]

第三步：推薦 Obsidian 外掛 (Community Plugins)​

為了讓日文寫作與 Quartz 自動發布更順暢，建議於 Obsidian 安裝以下擴充套件：

  1. Furigana / Japanese Helper
    • 用途：簡化振假名輸入，可直接用 [漢字]{かんじ} 替代繁瑣的 HTML 語法，部分外掛支援自動為句子補上讀音。
  2. Obsidian Git
    • 用途：免開啟終端機，直接在 Obsidian 介面內按快捷鍵或設定自動 Commit/Push 至 GitHub，觸發 Quartz 自動部署。
  3. Dataview
    • 用途：利用 SQL 般的語法將散落的單字或文法筆記自動動態彙整成清單（Quartz 4.0 支援將 Dataview 渲染為網頁靜態內容）。
  4. Excalidraw
    • 用途：支援在筆記中插入手繪畫布，適合用 Apple Pencil 或滑鼠繪製句型結構圖與心智圖，繪製完成會存成 SVG 圖檔嵌入筆記。
  5. Linter
    • 用途：儲存筆記時自動格式化 Markdown（如修正標頭、標籤格式），確保 pushed 到 GitHub 的程式碼格式一致。

第四步：本地預覽與測試​

在終端機中執行本地開發伺服器：

npx quartz build --serve

指令執行完成後，開啟瀏覽器造訪 http://localhost:8080，即可即時預覽你的 Quartz 筆記網站。

第五步：推送至 GitHub​

為了維護個人筆記的隱私與安全性，建議將 GitHub 儲存庫設定為 Private（私有）。

1. 在 GitHub 上建立新儲存庫​

  1. 前往 GitHub 點選 New repository。
  2. 填入專案名稱（例如 japanese-notes）。
  3. 可選擇 Private（私有）或 Public（公開）。
  4. 請勿勾選 Initialize with README。

2. 設定 Remote 並推送原始碼​

回到本機終端機，執行以下指令：

# 重設 Git remote 指向你自己的 GitHub 儲存庫
git remote set-url origin [https://github.com/YOUR_USERNAME/japanese-notes.git](https://github.com/YOUR_USERNAME/japanese-notes.git)

# 確保在 main 分支
git branch -M main

# 提交變更並推送
git add .
git commit -m "Initial commit for Quartz digital garden"
git push -u origin main

第六步：部署網站（Cloudflare Pages 推薦）​

若你的 GitHub 儲存庫設為 Private，使用 Cloudflare Pages 部署是完全免費且最方便的選擇。

使用 Cloudflare Pages 部署步驟​

  1. 登入 Cloudflare Dashboard。
  2. 進入 Workers & Pages > Create application > Pages > Connect to Git。
  3. 授權存取你的 GitHub，並選擇剛剛建立的 japanese-notes 儲存庫。
  4. 於 Build settings 設定如下：
    • Framework preset: None
    • Build command: npx quartz build
    • Build output directory: public
    • Environment Variables: 新增變數 NODE_VERSION = 18.14.0
  5. 點擊 Save and Deploy。

次後，只要你推送新的 Markdown 筆記到 GitHub，Cloudflare Pages 都會自動觸發建置並更新網站。

日文筆記專用技巧（Furigana 與別名）​

1. 振假名 (Furigana) 標註​

Quartz 預設支援原生 HTML <ruby> 標籤，可直接渲染漂亮的日文漢字讀音：

<ruby>漢<rt>かん</rt>字<rt>じ</rt></ruby>

2. YAML 別名 (Aliases) 設定​

在 Markdown 頂部標頭加入 aliases，可以確保輸入平假名、羅馬拼音或漢字都能被 Quartz 內建的搜尋引擎捕捉到：

---
title: 漢字
aliases:
  - かんじ
  - kanji
---

# 漢字 (かんじ)
這裡記錄關於日文漢字的學習筆記...

日常寫作與發布工作流​

配置完成後，未來的日常寫作流程非常簡單：

  1. 開啟 Obsidian，在 Vault 中直接新增或修改 .md 筆記。
  2. 完成寫作後，可透過 Obsidian Git 外掛 一鍵發布，或開啟終端機執行 Quartz 內建同步指令： 
    npx quartz sync
    • Quartz 會自動將更新提交（Commit）並推送到你的 GitHub，雲端託管平台會自動完成部署。

常見問題排解 (FAQ)​

Q1: 為什麼點擊內部連結會出現 404？​

請確認 Markdown 中的連結格式是否寫為 [[筆記名稱]] 或相對路徑 [連結文字](./filename.md)。確保目標檔案確實存在於 content/ 目錄內。

Q2: 想要修改網站主題顏色或字型？​

請編輯專案根目錄下的 quartz.config.ts 檔案，在 typography 與 colors 區塊自訂你喜愛的字型與顏色主題。 ``───
