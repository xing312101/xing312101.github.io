Agora(聲網)完整教學

從零開始使用 Agora 建立即時音視訊應用:概念、SDK、核心流程與實戰範例。 本文為通用教學,不涉及任何特定專案。

1. 什麼是 Agora​

Agora(中國品牌名「聲網」) 是一個提供**即時互動(RTE, Real-Time Engagement)**的雲端平台(PaaS)。它把複雜的即時音視訊技術包裝成簡單的 SDK,讓開發者不需自己架設媒體伺服器、處理 NAT 穿透、編解碼優化,就能快速做出:

  • 視訊 / 語音通話
  • 直播(互動直播、超低延遲直播)
  • 語音聊天室、Clubhouse 類應用
  • 線上教育、遠端醫療
  • 互動白板、螢幕分享

Agora 底層雖然也用 WebRTC 技術,但額外提供了全球分佈的 SD-RTN™ 軟體定義即時網路,大幅改善跨國、弱網環境下的品質。

2. Agora vs 原生 WebRTC​

面向原生 WebRTCAgora
信令伺服器自己架設內建
TURN / 媒體伺服器自己架設維護內建全球節點
多方會議(SFU)自己實作或整合內建
弱網優化自己處理內建抗丟包、自適應
跨平台一致性各平台差異大統一 SDK
錄製、轉碼、CDN 推流自己做雲端服務
成本伺服器 + 頻寬按用量付費
上手難度高低

一句話總結:自己用 WebRTC 是「從零打造」,用 Agora 是「呼叫 API」。小專案或要完全掌控用 WebRTC;要快速上線、跨國、多方、穩定,用 Agora 更省事。

3. 核心概念與名詞​

  • App ID:專案的唯一識別碼,在 Agora 控制台建立專案後取得。
  • Channel(頻道):一個虛擬房間。加入同一個 channel 名稱的使用者就能互相通訊。
  • UID:使用者在頻道中的唯一 ID(數字或字串)。
  • Token:身分驗證憑證,用來授權使用者加入頻道(正式環境必用)。
  • Role(角色):
    • Host / Broadcaster(主播):可發布音視訊。
    • Audience(觀眾):只接收,不發布(直播模式用)。
  • Track(軌):一條音訊或視訊串流。
  • SD-RTN™:Agora 的全球即時傳輸網路。

兩種頻道情境模式​

模式說明用途
Communication(通訊)所有人平等、都能發布視訊會議、1對1通話
Live Broadcast(互動直播)分主播/觀眾角色直播、線上教學

4. 帳號設定與前置作業​

步驟​

  1. 到 Agora 控制台 註冊帳號。
  2. 建立一個 Project,取得 App ID。
  3. 選擇驗證機制:
    • 測試階段:可用「App ID only(不含憑證)」模式,免 token。
    • 正式環境:啟用「App ID + Token」,並取得 App Certificate。
  4. 下載對應平台的 SDK(Web / Android / iOS / Flutter / React Native / Unity 等)。

免費額度​

Agora 每月提供 10,000 分鐘免費額度,足夠開發與小規模測試。

5. Token 驗證機制​

正式環境不可把 App Certificate 放在前端。Token 必須由你的後端伺服器產生。

流程​

   使用者 App                你的後端伺服器            Agora
      │                          │                     │
      │── 請求 token(帶 uid,channel)──>│              │
      │                          │  用 App Certificate  │
      │                          │  產生 token          │
      │<──────── token ──────────│                     │
      │                                                │
      │────── join(appId, channel, token, uid)───────>│
      │                                          驗證 token
      │<═══════════ 加入頻道成功 ══════════════════════│

後端產生 Token(Node.js 範例)​

const { RtcTokenBuilder, RtcRole } = require('agora-token');

function generateToken(channelName, uid) {
  const appId = process.env.AGORA_APP_ID;
  const appCertificate = process.env.AGORA_APP_CERTIFICATE;
  const role = RtcRole.PUBLISHER;
  const expireSeconds = 3600; // token 有效 1 小時
  const now = Math.floor(Date.now() / 1000);
  const privilegeExpiredTs = now + expireSeconds;

  return RtcTokenBuilder.buildTokenWithUid(
    appId, appCertificate, channelName, uid, role, privilegeExpiredTs
  );
}

// Express 端點
app.get('/rtc-token', (req, res) => {
  const { channel, uid } = req.query;
  const token = generateToken(channel, Number(uid));
  res.json({ token });
});

⚠️ Token 會過期。長時間通話需在 onTokenPrivilegeWillExpire 事件時向後端要新 token 並 renewToken()。

6. 實戰:Web 端視訊通話​

使用 agora-rtc-sdk-ng(Agora Web SDK 4.x)。

6.1 安裝​

npm install agora-rtc-sdk-ng

6.2 完整範例​

import AgoraRTC from 'agora-rtc-sdk-ng';

const APP_ID = 'your-app-id';
const CHANNEL = 'test-channel';

// 建立 client(mode: rtc 通訊 / live 直播)
const client = AgoraRTC.createClient({ mode: 'rtc', codec: 'vp8' });

let localTracks = { audioTrack: null, videoTrack: null };

async function join() {
  // 1. 向你的後端要 token
  const uid = Math.floor(Math.random() * 100000);
  const { token } = await fetch(`/rtc-token?channel=${CHANNEL}&uid=${uid}`).then(r => r.json());

  // 2. 監聽遠端使用者
  client.on('user-published', async (user, mediaType) => {
    await client.subscribe(user, mediaType);
    if (mediaType === 'video') {
      user.videoTrack.play(`remote-${user.uid}`); // 播到指定 DOM 元素
    }
    if (mediaType === 'audio') {
      user.audioTrack.play();
    }
  });

  client.on('user-unpublished', (user) => {
    console.log('使用者離開:', user.uid);
  });

  // 3. 加入頻道
  await client.join(APP_ID, CHANNEL, token, uid);

  // 4. 建立本地音視訊軌
  localTracks.audioTrack = await AgoraRTC.createMicrophoneAudioTrack();
  localTracks.videoTrack = await AgoraRTC.createCameraVideoTrack();
  localTracks.videoTrack.play('local-player'); // 播本地預覽

  // 5. 發布
  await client.publish([localTracks.audioTrack, localTracks.videoTrack]);
}

async function leave() {
  localTracks.audioTrack?.close();
  localTracks.videoTrack?.close();
  await client.leave();
}

6.3 HTML​

<div id="local-player" style="width:320px;height:240px"></div>
<div id="remote-12345" style="width:320px;height:240px"></div>
<button onclick="join()">加入</button>
<button onclick="leave()">離開</button>

7. 實戰:Flutter / 行動端​

使用官方 agora_rtc_engine 套件。

7.1 安裝​

# pubspec.yaml
dependencies:
  agora_rtc_engine: ^6.3.0
  permission_handler: ^11.0.0

7.2 核心程式​

import 'package:agora_rtc_engine/agora_rtc_engine.dart';

const appId = 'your-app-id';
const channel = 'test-channel';
const token = 'your-token'; // 從後端取得

late RtcEngine engine;

Future<void> initAgora() async {
  // 建立引擎
  engine = createAgoraRtcEngine();
  await engine.initialize(const RtcEngineContext(appId: appId));

  // 註冊事件
  engine.registerEventHandler(
    RtcEngineEventHandler(
      onJoinChannelSuccess: (connection, elapsed) {
        print('加入頻道成功: ${connection.channelId}');
      },
      onUserJoined: (connection, remoteUid, elapsed) {
        print('遠端使用者加入: $remoteUid');
      },
      onUserOffline: (connection, remoteUid, reason) {
        print('遠端使用者離開: $remoteUid');
      },
      onTokenPrivilegeWillExpire: (connection, token) async {
        // 向後端要新 token 並更新
        // final newToken = await fetchToken();
        // await engine.renewToken(newToken);
      },
    ),
  );

  // 啟用視訊
  await engine.enableVideo();
  await engine.startPreview();

  // 加入頻道
  await engine.joinChannel(
    token: token,
    channelId: channel,
    uid: 0, // 0 = 由 Agora 自動分配
    options: const ChannelMediaOptions(
      clientRoleType: ClientRoleType.clientRoleBroadcaster,
      channelProfile: ChannelProfileType.channelProfileCommunication,
    ),
  );
}

// 顯示本地畫面
Widget localView() => AgoraVideoView(
  controller: VideoViewController(
    rtcEngine: engine,
    canvas: const VideoCanvas(uid: 0),
  ),
);

// 顯示遠端畫面
Widget remoteView(int remoteUid) => AgoraVideoView(
  controller: VideoViewController.remote(
    rtcEngine: engine,
    canvas: VideoCanvas(uid: remoteUid),
    connection: const RtcConnection(channelId: channel),
  ),
);

// 離開清理
Future<void> dispose() async {
  await engine.leaveChannel();
  await engine.release();
}

📱 記得在 AndroidManifest.xml 與 iOS Info.plist 加上相機、麥克風權限,並在執行期用 permission_handler 請求授權。

8. 常用功能 API​

靜音 / 關閉視訊​

// Web
await localTracks.audioTrack.setEnabled(false); // 靜音
await localTracks.videoTrack.setEnabled(false); // 關鏡頭
// Flutter
await engine.muteLocalAudioStream(true);
await engine.muteLocalVideoStream(true);

切換前後鏡頭​

await engine.switchCamera();

切換角色(直播模式)​

await engine.setClientRole(role: ClientRoleType.clientRoleAudience);

調整視訊品質​

await engine.setVideoEncoderConfiguration(
  const VideoEncoderConfiguration(
    dimensions: VideoDimensions(width: 640, height: 360),
    frameRate: 15,
    bitrate: 400,
  ),
);

9. 進階功能​

Agora 除了基本音視訊,還提供一系列雲端服務:

功能說明
Cloud Recording(雲端錄製)把通話 / 直播錄下來存到你的雲儲存
Media Push(CDN 推流)把互動直播推到 CDN 給海量觀眾
Real-Time Messaging(RTM)即時訊息、信令、狀態同步
Screen Sharing(螢幕分享)分享畫面
Voice Changer / 美聲變聲、音效
Beauty / 美顏視訊美顏濾鏡
Extensions Marketplace第三方 AI 降噪、虛擬背景等外掛
Spatial Audio(空間音訊)3D 沉浸式音效

螢幕分享(Web)​

const screenTrack = await AgoraRTC.createScreenVideoTrack();
await client.unpublish(localTracks.videoTrack);
await client.publish(screenTrack);

雙流模式(大小流)​

弱網下觀眾可自動收看低解析度小流,節省頻寬:

await client.enableDualStream();

10. 授權與計費​

需要 License 嗎?​

不需要傳統意義上的「軟體授權(License Key)」,但需要註冊帳號取得 App ID,並依用量付費。 Agora 是雲端服務(PaaS),不是一次買斷的軟體。

項目需要嗎說明
軟體授權金 / License Key❌ 不需要SDK 免費下載使用,沒有序號、沒有買斷授權
Agora 帳號 + App ID✅ 需要控制台註冊、建專案取得,是「識別」不是「授權費」
App Certificate + Token✅ 正式環境需要用於身分驗證(防盜用),自己後端產生,免費
付費(按用量)⚠️ 超過免費額度才要按「分鐘 × 解析度」計費

重點:

  1. SDK 本身免費、不需 license key —— 直接 npm install / 加 Flutter 套件就能用。
  2. 每月 10,000 分鐘免費額度,開發、測試、小規模上線通常免費。
  3. 超過免費額度後才按用量付費,這是「服務費」不是「授權費」。
  4. 唯一要「申請」的是 帳號 / 專案 / App ID,免費且即時開通。

要注意的條款:

  • 不是開源:SDK 是閉源專有軟體,只是免費使用,不能自架、不能拿掉對 Agora 雲的依賴(廠商綁定)。
  • 商用同一模式:個人或公司商用都走用量計費,沒有額外商業授權門檻。
  • 中國大陸落地:若使用者位於中國大陸境內,依當地法規可能需使用 Agora 中國區(聲網)服務並完成實名 / 備案,這屬「合規」而非 SDK 授權。

對比:真正「完全免費且無廠商綁定」的是自己用原生 WebRTC,但需自架信令 + TURN + SFU,工程與伺服器成本高很多。詳見 WebRTC 教學。

計費方式​

Agora 按每分鐘用量 × 解析度等級計費,音訊最便宜,視訊依解析度分級(SD / HD / Full HD):

  • 音訊:最便宜
  • 視訊 SD(≤ 640×480):中
  • 視訊 HD(≤ 1280×720):較高
  • 視訊 Full HD(> 720p):最高

每月前 10,000 分鐘免費。

省錢與優化建議​

  • 觀眾用 Audience 角色,不佔發布流量。
  • 用雙流模式讓弱網觀眾走小流。
  • 不用時記得 leaveChannel() / close() 釋放資源,避免持續計費。
  • 依情境調整解析度,不要一律 1080p。

11. 常見問題與除錯​

問題可能原因解法
加入頻道失敗 invalid tokentoken 過期或參數不符確認 channel、uid 與後端一致
聽不到聲音未 subscribe 或未 play audio確認 user-published 有處理 audio
看不到遠端畫面DOM 元素不存在play() 前確認容器已 render
Web 端 NotAllowedError非 HTTPS 或使用者拒絕授權用 https,並引導使用者授權
行動端黑畫面權限沒給執行期請求相機/麥克風權限
跨國延遲高未就近接入Agora 自動選節點,通常已優化;檢查網路

除錯工具​

  • Agora 控制台的 Analytics:可查每次通話的品質數據(延遲、丟包、卡頓)。
  • SDK log:設定 log level 觀察詳細訊息。

總結​

使用 Agora 的三個關鍵心智模型:

  1. App ID + Channel + Token:身分與房間的三要素,token 由後端產生。
  2. Publish / Subscribe 模型:自己 publish 本地軌,監聽 user-published 去 subscribe 遠端軌。
  3. 雲端服務隨叫隨用:錄製、CDN 推流、RTM、美顏都是加購 API,不用自己做。

Agora 把即時音視訊最難的部分(全球網路、弱網優化、多方轉發)都幫你處理好,你只要專注在應用邏輯上。與原生 WebRTC 相比,它用「付費」換「省時省心」。
