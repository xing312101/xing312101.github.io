手機實機：讓 agent 用 Appium 操作 iPhone 與 Android

目標：手機用 USB 接在電腦上，agent 只靠 shell 指令（curl）就能截圖 → 看圖 → 點擊／滑動／打字， 像人一樣操作整支手機。範圍不限瀏覽器，系統對話框、相簿挑選器、其他 App 都點得到。

不需要相機、第三方 App 的話，先用模擬器比較省事；同一套 Appium 也能開模擬器。

1. 架構​

agent ──HTTP（curl）──▶ Appium 伺服器（電腦上）──▶ 手機上的代理程式 ──▶ 整支手機
                                                    iOS：WebDriverAgent（XCUITest）
                                                    Android：UiAutomator2 server
iOSAndroid
電腦只能是 Mac（要 Xcode 簽章）macOS／Linux／Windows 都可以
Appium driverxcuitestuiautomator2
手機上的代理程式WebDriverAgent，要用你的 Apple ID 簽章後安裝第一次連線時自動安裝
不用 Appium 的替代方案沒有實用的adb 就能點擊、截圖（見第 5 節）

2. 共同準備：安裝 Appium​

項目版本／指令
Node.jsAppium 3 需要 ^20.19、^22.12 或 >=24，npm >=10
Appium裝在獨立資料夾，不要裝全域
mkdir -p ~/tools/appium && cd ~/tools/appium
npm init -y
npm install appium
npx appium driver install xcuitest      # iOS
npx appium driver install uiautomator2  # Android
npx appium driver list --installed

每個 driver 都有自我檢查，缺什麼會直接列出來：

npx appium driver doctor xcuitest
npx appium driver doctor uiautomator2

啟動伺服器（只聽本機，預設會聽所有網卡，同網段的人都能遙控你的手機）：

npx appium --address 127.0.0.1 --port 4723 --log-level warn

3. iOS 設定​

3.1 電腦端​

項目說明
Xcode完整的 Xcode（App Store），不是只有 Command Line Tools。裝完開一次、同意授權
Apple IDXcode → Settings → Accounts 登入。免費帳號也可以，但簽出來的 App 7 天後失效
Team ID同一個畫面點帳號就看得到（10 碼英數字），開 session 時要填
libimobiledevice（選用）brew install libimobiledevice，用 idevice_id -l 查手機 UDID

查 UDID 也可以不裝任何東西：xcrun xctrace list devices。

3.2 手機端​

  1. 用 USB 接上電腦，手機上按「信任這部電腦」
  2. 開發者模式：設定 → 隱私權與安全性 → 開發者模式 → 開啟（會重新開機）
    • 這個選項要先接過 Xcode 才會出現：Xcode → Window → Devices and Simulators 看到手機就有了
  3. 第一次裝好 WebDriverAgent 後，若用免費帳號：設定 → 一般 → VPN 與裝置管理 → 信任你的開發者憑證
  4. 設定 → 開發者 → 若有「啟用 UI 自動化」（Enable UI Automation）就打開
  5. 測試期間把 設定 → 螢幕顯示與亮度 → 自動鎖定 設成「永不」，鎖屏時什麼都點不到
tip

XCUITest 不需要 Safari 的「網頁檢閱器」。只有要讀網頁 DOM、切到 WebView context 時才需要開。

3.3 開 session​

第一次會用 Xcode 編譯、簽章、安裝 WebDriverAgent，要好幾分鐘；之後幾秒就連上。

curl -s -X POST http://127.0.0.1:4723/session \
  -H 'Content-Type: application/json' -d '{
  "capabilities": { "alwaysMatch": {
    "platformName": "iOS",
    "appium:automationName": "XCUITest",
    "appium:udid": "<你的 UDID>",
    "appium:xcodeOrgId": "<你的 Team ID>",
    "appium:xcodeSigningId": "Apple Development",
    "appium:updatedWDABundleId": "com.example.wda",
    "appium:bundleId": "com.apple.mobilesafari",
    "appium:noReset": true,
    "appium:wdaLaunchTimeout": 300000,
    "appium:newCommandTimeout": 1800
  }}}' | tee session.json
capability為什麼要設
updatedWDABundleId預設的 bundle ID 被別人註冊過，簽章會失敗；換成你自己的反向網域
noReset不要清掉 App 的資料（登入狀態、Cookie）
bundleIdsession 開起來後先停在哪個 App；Safari 是 com.apple.mobilesafari
wdaLaunchTimeout第一次編譯很久，預設逾時不夠
newCommandTimeoutagent 思考時間長，閒置太久 session 會被收掉（秒）
warning

手機上已經裝過一個 WebDriverAgent（以前有人設過）時，直接沿用它的 bundle ID，不要再多裝一個。

4. Android 設定​

4.1 電腦端​

項目說明
Android SDK裝 Android Studio，或只裝 command-line tools；至少要有 platform-tools
ANDROID_HOME指到 SDK 目錄（例：~/Library/Android/sdk）
JDK17 以上，設好 JAVA_HOME
scrcpy（選用）brew install scrcpy，讓人在電腦上同步看手機畫面，方便盯著 agent

只想用 adb（第 5 節）的話：brew install android-platform-tools 就夠了。

4.2 手機端​

  1. 設定 → 關於手機 → 連點「版本號碼」7 次，開啟開發人員選項
  2. 開發人員選項 → USB 偵錯 開啟
  3. 接上 USB，手機跳出 RSA 指紋時按「一律允許」
  4. 部分品牌（例如小米）還要開「USB 偵錯（安全性設定）」與「透過 USB 安裝」，不然點擊無效或裝不了代理程式
  5. 確認連上：adb devices 看到 device（不是 unauthorized）

4.3 開 session​

curl -s -X POST http://127.0.0.1:4723/session \
  -H 'Content-Type: application/json' -d '{
  "capabilities": { "alwaysMatch": {
    "platformName": "Android",
    "appium:automationName": "UiAutomator2",
    "appium:udid": "<adb devices 列出的序號>",
    "appium:noReset": true,
    "appium:newCommandTimeout": 1800
  }}}' | tee session.json

5. Android 的輕量做法：只用 adb​

不裝 Appium 也能讓 agent 操作 Android，指令少、反應快：

動作指令
截圖adb exec-out screencap -p > shot.png
點擊adb shell input tap 540 1200
滑動adb shell input swipe 540 1600 540 600 300
打字（英數）adb shell input text 'hello'（空白寫成 %s）
返回／主畫面adb shell input keyevent 4／3
開網址adb shell am start -a android.intent.action.VIEW -d 'https://example.com'
讀畫面元素adb shell uiautomator dump /sdcard/ui.xml && adb pull /sdcard/ui.xml

input text 打不了中文；要打中文或要可靠地找元素，再改用 Appium。

6. 包成 agent 好用的指令​

agent 每一步都是「截圖 → 看圖 → 決定座標 → 點擊」。把常用動作包成 shell 函式，放在固定路徑， 在專案的 agent 說明檔（例如 CLAUDE.md）寫一句「source ~/tools/appium/device.sh 後用 tap／shot」。

# ~/tools/appium/device.sh
SID=$(python3 -c "import json;print(json.load(open('$HOME/tools/appium/session.json'))['value']['sessionId'])")
A=http://127.0.0.1:4723/session/$SID
OUT=${OUT:-/tmp/device}; mkdir -p "$OUT"

# 點擊：座標單位見下方說明
tap() {
  curl -s -X POST $A/actions -H 'Content-Type: application/json' -d "{\"actions\":[{\"type\":\"pointer\",\"id\":\"f\",
    \"parameters\":{\"pointerType\":\"touch\"},\"actions\":[{\"type\":\"pointerMove\",\"duration\":0,\"x\":$1,\"y\":$2},
    {\"type\":\"pointerDown\",\"button\":0},{\"type\":\"pause\",\"duration\":80},{\"type\":\"pointerUp\",\"button\":0}]}]}" >/dev/null
}
# 垂直滑動：swipe X 起點Y 終點Y（往上滑＝內容往下捲）
swipe() {
  curl -s -X POST $A/actions -H 'Content-Type: application/json' -d "{\"actions\":[{\"type\":\"pointer\",\"id\":\"f\",
    \"parameters\":{\"pointerType\":\"touch\"},\"actions\":[{\"type\":\"pointerMove\",\"duration\":0,\"x\":$1,\"y\":$2},
    {\"type\":\"pointerDown\",\"button\":0},{\"type\":\"pointerMove\",\"duration\":400,\"x\":$1,\"y\":$3},
    {\"type\":\"pointerUp\",\"button\":0}]}]}" >/dev/null
}
# 截圖：shot 名稱 → $OUT/名稱.png
shot() {
  curl -s $A/screenshot | python3 -c "import json,sys,base64;open('$OUT/$1.png','wb').write(base64.b64decode(json.load(sys.stdin)['value']))"
}
# 打字到目前有焦點的輸入框（中文可以）
typ() {
  E=$(curl -s $A/element/active | python3 -c "import json,sys;v=json.load(sys.stdin)['value'];print(next(iter(v.values())))")
  curl -s -X POST $A/element/$E/value -H 'Content-Type: application/json' -d "{\"text\":\"$1\"}" >/dev/null
}
# 開網址（在目前的瀏覽器）
url() { curl -s -X POST $A/url -H 'Content-Type: application/json' -d "{\"url\":\"$1\"}" >/dev/null; }
# 切到別的 App：app com.apple.mobilesafari／com.android.chrome
app() {
  curl -s -X POST $A/appium/device/activate_app -H 'Content-Type: application/json' \
    -d "{\"bundleId\":\"$1\",\"appId\":\"$1\"}" >/dev/null
}
# 畫面元素樹（找不到座標時用文字找）
src() { curl -s $A/source | python3 -c "import json,sys;print(json.load(sys.stdin)['value'])"; }

座標單位（最常出錯的地方）​

平台tap 的單位跟截圖的關係
iOSpoint截圖是 pixel，要除以螢幕倍率（多數 iPhone 是 3，少數是 2）
Androidpixel跟截圖一致

agent 讀圖時，圖片常被縮小顯示，它看到的座標還要先換回原圖尺寸。 在說明檔寫清楚換算公式，例如：「原圖 1170×2532、倍率 3，point = 原圖 pixel ÷ 3」。

7. 注意事項​

danger

截圖會送給模型，手機上的通知、聊天內容也會一起入鏡。用測試用的手機與帳號（見總覽）。

  • App 內建瀏覽器跟 Safari／Chrome 不一樣：通訊軟體、社群 App 內開的網頁，常常不支援列印、 下載、開新視窗，選單裡也未必有「用瀏覽器開啟」。要測就在那個 App 裡實際測，不要拿 Safari 的結果代替
  • 登入狀態各自獨立：App 內建瀏覽器與 Safari／Chrome 的 Cookie 不共用
  • 系統對話框點得到：相簿挑選器、權限詢問、分享選單都能用 tap 操作
  • iOS 新版的 idevicescreenshot 常常失敗，截圖一律走 Appium 的 /screenshot
  • safaridriver、ios_webkit_debug_proxy 只能控制網頁、還要開網頁檢閱器，不能點系統畫面；要操作整支手機用 XCUITest
  • 每步截圖前等 1～3 秒（sleep），畫面還在動畫時截到的是舊畫面
  • 免費 Apple 帳號簽的 WebDriverAgent 7 天後打不開，重開一次 session 就會重新簽
  • 用完收掉：curl -X DELETE $A，再停掉 Appium；手機上的 WebDriverAgent 可以留著，下次直接用

8. 疑難排解​

症狀原因與處理
開 iOS session 卡很久後逾時第一次在編譯 WebDriverAgent；調大 wdaLaunchTimeout，看 Appium log
xcodebuild failed with code 65簽章問題：Team ID 錯、bundle ID 被佔用（改 updatedWDABundleId）、Xcode 沒登入帳號
手機上 WebDriverAgent 一開就關沒信任開發者憑證（3.2 第 3 步），或免費帳號的簽章過期
找不到「開發者模式」先在 Xcode 的 Devices 視窗連一次手機
adb devices 顯示 unauthorized手機上沒按允許；拔掉重插，或撤銷 USB 偵錯授權後重來
Android 點擊沒反應品牌額外的「USB 偵錯（安全性設定）」沒開
session 用一用就失效newCommandTimeout 太短，或手機自動鎖定了
點的位置偏掉座標單位錯（見第 6 節），或沒換回原圖尺寸
