openssl s_time 測試連線測試 SSL/TLS 握手性能​

openssl s_time -connect <host:port> [options]
-connect host:port → 目標伺服器和端口，例如 example.com:443
s_time → SSL/TLS 性能測試命令

options:
-new	每次都建立新連線（可以測試握手耗時）
-cipher <cipher>	指定使用的加密套件，例如 ECDHE-RSA-AES256-GCM-SHA384
-CAfile <file>	指定憑證檔案，用於驗證伺服器
-www <path>	發送 HTTP GET 請求，測試完整握手 + 傳輸性能
-tls1_2 / -tls1_3	指定 TLS 版本

# Make sure proxies don't deliver the wrong content
Header append Vary User-Agent env=!dont-vary
