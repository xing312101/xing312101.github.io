Claude Code Usage Monitor 安裝教學（從安裝 uv 開始）

1. 安裝 uv​

Linux / macOS​

curl -LsSf https://astral.sh/uv/install.sh | sh

安裝完成後會看到類似訊息：

installing to /home/<user>/.local/bin
  uv
  uvx
everything's installed!

載入環境變數​

依照安裝訊息執行：

source $HOME/.local/bin/env

或直接指定路徑：

source /home/<user>/.local/bin/env

驗證安裝​

uv --version

成功範例：

uv 0.11.21 (aarch64-unknown-linux-gnu)

2. 安裝 Claude Code Usage Monitor​

使用 uv 安裝：

uv tool install claude-monitor

3. 驗證安裝​

claude-monitor --help

如果能正常顯示說明，即表示安裝成功。

4. 啟動監控器​

最簡單的方式：

claude-monitor

也可以使用別名：

cmonitor
ccmonitor
ccm

5. 常用設定​

Claude Pro​

claude-monitor --plan pro

Claude Max 5x​

claude-monitor --plan max5

Claude Max 20x​

claude-monitor --plan max20

自動偵測（推薦）​

claude-monitor --plan custom

6. 深色主題​

claude-monitor --theme dark

7. 台灣時區設定​

claude-monitor \
  --timezone Asia/Taipei \
  --theme dark

Docker 使用者注意事項​

如果是在 Docker 容器中執行：

node@container-id:/app/...

即使 monitor 安裝成功，也需要能夠讀取 Claude Code 的使用資料。

先確認：

ls -la ~/.claude

如果出現：

No such file or directory

代表容器內沒有 Claude Code 的資料目錄。

此時需要：

  • 將主機的 ~/.claude 掛載進 Docker 容器
  • 或直接在安裝 Claude Code 的主機環境執行 monitor

否則會出現找不到資料或沒有統計資訊的情況。

常見問題：安裝 uv 後找不到指令​

如果安裝完成後執行：

uv --version

出現：

bash: uv: command not found

通常是 PATH 尚未更新。

執行：

source $HOME/.local/bin/env

再測試：

uv --version

若仍有問題：

export PATH="$HOME/.local/bin:$PATH"

之後再次執行：

uv --version

更新 Claude Monitor​

uv tool upgrade claude-monitor

完整安裝流程​

curl -LsSf https://astral.sh/uv/install.sh | sh

source $HOME/.local/bin/env

uv --version

uv tool install claude-monitor

claude-monitor --plan custom --timezone Asia/Taipei --theme dark
