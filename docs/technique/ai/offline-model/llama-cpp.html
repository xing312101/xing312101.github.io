macOS 專屬：llama.cpp 安裝、Qwen3.6（35B-A3B / 27B）配置與自動化部署全攻略

本指南專為 macOS (Apple Silicon M 系列晶片) 打造，整合了 llama.cpp 的安裝、Qwen3.6-35B-A3B 各量化版本（Q4/Q5/Q6）與 Qwen3.6-27B（Dense）的配置、長上下文（64K）進階調校，以及專屬的「一鍵自動化啟動」設定，幫助您打造最完美的本地 AI 開發環境。

1. Mac 統一記憶體 (Unified Memory) 與版本挑選建議​

由於 Qwen3.6-35B-A3B 屬於 MoE（混合專家）架構，強烈建議將模型「100% 全塞」進 Mac 的統一記憶體中，才能完全釋放 Metal GPU 的極致推理速度。請依您的 Mac 規格挑選合適版本：

量化版本檔案大小建議 Mac 記憶體規格說明
Q4_K_M約 20 GB24GB / 36GB資源消耗低，速度最快，36GB 機型跑起來最無壓力。
Q5_K_M約 25 GB48GB / 64GB程式碼邏輯與精確度最平衡的黃金版本。
Q6_K約 29 GB64GB / 96GB 或以上幾近無損的高精確度，適合超大型工作流。

另一路線 — 稠密 27B：想要單一稠密 (Dense) 模型推理，可用 Qwen3.6-27B 的 Q8_0（幾近無損）。它每 token 都跑完整參數，速度較 35B-A3B（MoE）稍慢但推理紮實，啟動指令見 §3 方案 D。

長上下文：以上皆以 16K 上下文為例；要開到 64K (--ctx-size 65536)，需搭配 Flash Attention 與 q8_0 的 KV 快取量化來壓低記憶體，見 §3 方案 D 與 §4 參數表。

2. 安裝 llama.cpp​

在 Mac 上最穩定的安裝方式是使用 Homebrew，它會自主下載並自動為您的 Mac 晶片編譯並啟用 Metal 硬體加速 (GPU)：

brew install llama.cpp

3. 各版本一鍵啟動指令 (自動從 Hugging Face 下載)​

llama.cpp 支援模糊比對，會自動尋找倉庫中對應的 .gguf 檔案。請依據您的硬體需求，挑選其中一個指令複製到終端機執行：

🟢 方案 A：部署 Q4_K_M 版本（最速、最省空間）​

使用 lmstudio-community 倉庫：

llama-server -hf lmstudio-community/Qwen3.6-35B-A3B-GGUF:Q4_K_M --ctx-size 16384 -ngl 99 --port 8080

🟡 方案 B：部署 Q5_K_M 版本（精度與速度平衡）​

注意：因 lmstudio 未打包 Q5，此處改用大提琴大神的完整倉庫 bartowski：

llama-server -hf bartowski/Qwen3.6-35B-A3B-GGUF:Q5_K_M --ctx-size 16384 -ngl 99 --port 8080

🔴 方案 C：部署 Q6_K 版本（極致高精度）​

使用 lmstudio-community 倉庫：

llama-server -hf lmstudio-community/Qwen3.6-35B-A3B-GGUF:Q6_K --ctx-size 16384 -ngl 99 --port 8080

🔵 方案 D：長上下文 (64K) 進階配置（Flash Attention + KV 量化）​

把上下文從 16K 拉到 64K (--ctx-size 65536)。關鍵在多加 -fa auto（啟用 Flash Attention）與 -ctk q8_0 -ctv q8_0（把 KV 快取量化為 q8_0，約省一半 KV 記憶體），否則 64K 的 KV 快取會吃爆統一記憶體。

Qwen3.6-35B-A3B（MoE）Q6_K：

llama-server -hf lmstudio-community/Qwen3.6-35B-A3B-GGUF:Q6_K --ctx-size 65536 -ngl 99 -fa auto -ctk q8_0 -ctv q8_0 --port 8080

Qwen3.6-27B（Dense）Q8_0：

llama-server -hf lmstudio-community/Qwen3.6-27B-GGUF:Q8_0 --ctx-size 65536 -ngl 99 -fa auto -ctk q8_0 -ctv q8_0 --port 8080
  • 27B 為稠密 (Dense) 模型（非 A3B 的 MoE），Q8_0 幾近無損；每 token 需跑完整參數，速度較 35B-A3B 稍慢但推理紮實。
  • 記憶體吃緊時：先把 --ctx-size 降回 32768 (32K) 或 16384，仍保留 -fa／KV 量化即可再省一截。

4. 關鍵參數與 Mac 優化核心技巧​

參數說明Mac 最佳化配置技巧
-hf指定 Hugging Face 上的模型儲存庫與標籤。格式為 用戶名/儲存庫名稱:量化標籤
-ngl / --gpu-layers要將多少層模型卸載給 Mac GPU 處理。必須是單減號 -ngl（若用雙減號須改打 --gpu-layers）。Mac 務必設 99（全塞）以確保流暢度。
--ctx-size / -c上下文視窗大小 (Context Window)。預設為 16384 (16K)。卡頓（記憶體不足）就降到 8192 (8K)；要上拉到 65536 (64K) 請搭配 -fa 與 KV 量化（見 §3 方案 D）。
-fa / --flash-attn啟用 Flash Attention（auto 讓 llama.cpp 自行判斷是否開啟）。開長上下文或量化 KV 快取時建議開啟：省記憶體、加速 attention。量化 V 快取（-ctv）通常也需要它。
-ctk / --cache-type-kKV 快取中 K 的資料型別。設 q8_0 可將 K 快取量化、約省一半記憶體，換取 64K 這類長上下文（預設 f16）。
-ctv / --cache-type-vKV 快取中 V 的資料型別。設 q8_0 同上；量化 V 快取通常需搭配 -fa。
--port啟動的本地伺服器 Port 號。預設為 8080（此為網頁開發常用免權限埠口，可自由調整為 8081、9000 等）。

5. 自動化啟動設定（免每次輸入長指令）​

為了避免每次開啟都要複製一長串指令，請選擇以下其中一種自動化偷懶大招（以下以 Q6_K 為例，可自由更換內部指令）：

🏎️ 方案 A：設定終端機指令簡稱（Alias）—— 推薦！​

  1. 開啟終端機，編輯 Mac 的環境設定檔： 
    nano ~/.zshrc
  2. 移到檔案最底部，將以下代碼複製並貼上： 
    alias qwen="llama-server -hf lmstudio-community/Qwen3.6-35B-A3B-GGUF:Q6_K --ctx-size 16384 -ngl 99 --port 8080"
  3. 按下 Control + O（寫入），按 Enter 確認，再按 Control + X 離開。
  4. 輸入以下指令讓設定立刻生效： 
    source ~/.zshrc
  • 如何使用：以後打開終端機只要輸入 qwen 即可啟動模型。

🖱️ 方案 B：製作桌面一鍵點擊檔（.command）​

  1. 打開 Mac 內建的**「文字編輯」App** (TextEdit)。
  2. 點選選單列的「格式」 $\rightarrow$ 「製作純文字」（必須切換為純文字格式）。
  3. 將以下內容完整複製並貼入檔案中： 
    #!/bin/bash
    llama-server -hf lmstudio-community/Qwen3.6-35B-A3B-GGUF:Q6_K --ctx-size 16384 -ngl 99 --port 8080
  4. 儲存檔案至**「桌面」**，並取名為：run_qwen.command。
  5. 打開終端機輸入以下指令，開通執行權限（僅需設定一次）： 
    chmod +x ~/Desktop/run_qwen.command
  • 如何使用：需要用到 AI 時，直接在桌面雙擊 run_qwen.command 即可啟動。關閉彈出的終端機視窗即可停止服務。

6. 驗證與編輯器 API 串接​

當終端機日誌停止滾動，並出現 ggml_metal_init: allocating 與 HTTP server listening on http://127.0.0.1:8080 時，即代表本地 API 伺服器已就緒。

終端機測試 (cURL)​

您可以另開一個終端機視窗，執行以下指令驗證模型是否能正常思考：

curl http://localhost:8080/v1/chat/completions \
-H "Content-Type: application/json" \
-d '{
  "messages": [
    {"role": "user", "content": "請用 Python 寫一個快排演算法（Quick Sort）"}
  ]
}'

開發工具串接設定​

llama-server 架設的 API 與 OpenAI 格式 100% 相容。您可以直接將其設定至各大 AI 程式碼編輯器或外掛（如 Cline、Cursor、Continue.dev 或 Tabby）中，享受完全隱私、零成本的本地 AI 開發：

  • API Base URL：http://localhost:8080/v1 (注意：若修改了 --port 參數，此處 Port 號需同步修改)
  • API Key：隨意填寫（例如：mac-local）
  • Model Name：隨意填寫（例如：qwen3.6）
