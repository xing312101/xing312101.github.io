卷積神經網路 CNN

可以進行特徵萃取(Feature Extraction) 主要用在影像辨識跟自然語言處理(NLP) 有效減輕NN訓練的負載

步幅 (Stride)​

filter 每次滑動的格數。stride 越大，輸出特徵圖越小、計算量越少（相當於下採樣）。

padding 填補​

  • same：補零讓輸出尺寸 = 輸入（sizeᵢₙ == sizeₒᵤₜ）。
  • valid：不補零，輸出會縮小。

pooling layer​

壓縮圖片並保留重要資訊，不訓練、純粹壓縮，是不可逆的壓縮方式（常用 Max / Average pooling）。

pooling vs kernal​

pooling 不訓練，純壓縮 kernal 會訓練

特徵圖大小 Feature map size​

fllor((W + 2 * pad - ks) / S) + 1

  1. 輸入圖: W * W
  2. Filter (kernel): ks * ks
  3. Stride: S
  4. Padding: pad

Flatten layer​

將2-D轉乘1-D，它沒有row or column

CNN 視覺化​

  • 看各層 feature map / filter 學到什麼：淺層抓邊緣、紋理，深層抓部件、物件。
  • Grad-CAM：畫出模型判斷時關注影像的哪塊區域（熱力圖）。
  • 架構圖工具：netron.app（見下方輔助工具）。

Multiclass classification​

用Softmax activation啟動函數將 z 轉換為類別機率值f

網路層​

典型堆疊：Conv → activation(ReLU) → Pooling（重複數次做特徵萃取）→ Flatten → Dense（分類）→ 輸出層。

應用：物件偵測 YOLO。
