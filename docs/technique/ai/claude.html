Claude Code CLI 安裝與設定教學（macOS / Linux / WSL / Windows）

Claude Code CLI 是 Anthropic 官方的 AI coding agent，可直接在終端機中使用。

1. 安裝 Claude Code CLI​

方法一（推薦：官方 Native Installer）​

curl -fsSL https://claude.ai/install.sh | bash

方法二（Homebrew）​

brew install --cask claude-code

方法三（Windows PowerShell）​

irm https://claude.ai/install.ps1 | iex

方法四（Windows CMD）​

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

2. 驗證安裝是否成功​

claude --version

如果成功會顯示版本號，例如：

claude 1.x.x

3. 初始化登入（非常重要）​

安裝完成後執行：

claude

接著會：

  • 開啟瀏覽器
  • 登入 Claude 帳號
  • 授權 CLI 存取

登入成功後 CLI 才能正常使用。

4. 基本檢查與診斷​

claude doctor

用途：

  • 檢查 CLI 是否安裝完整
  • 檢查 login 狀態
  • 檢查系統環境

5. 基本使用方式​

進入專案目錄後：

cd your-project
claude

或直接執行任務：

claude "refactor this project to use TypeScript"

6. 更新 Claude Code CLI​

自動更新（預設）​

Native install 會自動背景更新。

手動更新​

claude update

7. 停用或控制更新（進階）​

在設定檔 settings.json：

{
  "env": {
    "DISABLE_AUTOUPDATER": "1"
  }
}

8. 常見安裝方式選擇建議​

環境建議方式
macOScurl / brew
Linuxcurl
WindowsPowerShell
WSLcurl

9. 常見問題​

❌ claude: command not found​

解法：

export PATH="$HOME/.local/bin:$PATH"

或重新開 shell：

source ~/.bashrc

❌ 無法登入​

先確認：

claude doctor

再重新：

claude

❌ CLI 沒反應 / 卡住​

通常是：

  • 沒登入
  • 網路問題
  • token 過期

解法：

claude logout
claude

10. 完整快速安裝流程（懶人版）​

curl -fsSL https://claude.ai/install.sh | bash

claude --version

claude

claude doctor

11. 補充：Claude Code 是什麼？​

Claude Code 是一個「agentic coding CLI」，可以：

  • 讀寫專案
  • 執行 shell commands
  • 自動改 code
  • 管理 repo
  • 協助 debug / refactor

核心運作方式是：

model → decision → tool execution → loop

12. 分開session​

{
  env: {
    CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC: 1
  }
}
