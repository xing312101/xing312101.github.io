常見問題對照

1. Android（adb）​

錯誤／現象原因處理
adb devices 顯示 unauthorized手機還沒允許這台電腦偵錯手機上按「允許」，勾「一律允許」
adb devices 是空的線只能充電、USB 偵錯沒開、驅動換線；確認開發人員選項
截圖檔打不開用了 adb shell screencap，換行被轉碼改用 adb exec-out screencap -p
uiautomator dump 回 null root node畫面正在切換或 App 剛啟動等 1～2 秒再讀一次
ERROR: could not get idle state畫面上有持續的動畫；或另一個自動化工具正在用 UiAutomation關掉系統動畫；關掉 Appium 等工具
備份的 tar 檔解不開錯誤訊息被 exec-out 混進輸出在手機端加 2>/dev/null，見 Android 篇 7.3
點擊位置偏掉用了縮小後截圖上的座標；或鍵盤把版面推上去見操作守則第 2 節
input text 打不出中文只支援 ASCII用 ADBKeyBoard，或改成捲動清單選取
INSTALL_FAILED_UPDATE_INCOMPATIBLE簽章不同先備份 APK 與資料，再移除後安裝
INSTALL_FAILED_VERSION_DOWNGRADE版號比較舊adb install -r -d
run-as: package not debuggable商店版（release）不能用 run-as沒辦法備份資料；換帳號前確認知道原帳號密碼
Demo Mode 指令沒效果廠牌不支援或只支援部分截圖後裁掉狀態列
第一次開 App 被權限框擋住還沒授權啟動前 pm grant

2. iOS（devicectl／WebDriverAgent）​

錯誤／現象原因處理
Could not start screenshotr service: Invalid serviceiOS 17 以上，idevicescreenshot 不能用改用 WebDriverAgent
flutter screenshot 說裝置不支援同上改用 WebDriverAgent 或 integration_test
No Accounts: Add a new account in Accounts settingsXcode 沒有登入帳號Xcode → Settings → Accounts 登入
PLA Update available團隊有新版條款沒同意Account Holder 到開發者網站同意
No profiles for '….xctrunner' were found不能自動產生描述檔先解決上面兩項；不要借用其他 App 的描述檔
Unable to launch … because it has an invalid code signature 或未受信任第一次執行用個人／企業簽章的 App設定 → 一般 → VPN 與裝置管理 → 信任
ServerURLHere 沒出現手機鎖定、開發者模式沒開解鎖後重跑；看 log 最後幾行
curl localhost:8100 連不上iproxy 沒開或 UDID 錯用 UDID，不是 devicectl 的 Identifier
WDA 指令一直沒回應App 有持續動畫，WDA 在等畫面靜止建 session 時 shouldWaitForQuiescence: false
點擊位置差很多用了像素而不是點像素 ÷ 螢幕倍率（通常 3）
原本會動，過一陣子全部沒回應手機自動鎖定，WDA 跟著停了自動鎖定改「永不」，重新啟動 WDA
wda/keys 打字沒反應輸入框沒有焦點先點一下輸入框再送字
新的 iPhone 簽不過手機還沒登記到團隊建置時加 -allowProvisioningDeviceRegistration

3. Flutter integration_test​

錯誤／現象原因處理
截圖資料夾是空的或是舊檔截圖在最後才一次寫出，中途斷線就全沒了用測試最後印出的標記判斷成功，每次先清空資料夾
Android 截圖是空白沒呼叫 convertFlutterSurfaceToImage()在第一次截圖前呼叫（只在 Android）
pumpAndSettle timed out畫面上有不會停的動畫改用 tester.pump(Duration) 固定等待
截不到來電畫面、權限框、地圖integration_test 只截 Flutter 畫的那一層改用 adb／WDA
iPhone 多個測試檔只跑了第一個實機無法連續重裝啟動一次一個檔案
Cannot start app on wirelessly tethered iOS deviceflutter test 不支援無線接線，或用 flutter drive --publish-port
VM Service not discovered after 75siPhone 上的「區域網路」權限沒允許手機上按允許
跑完 App 不見了flutter drive 結束時會移除 App需要的話重新安裝

4. 網頁（Playwright）​

錯誤／現象原因處理
登入顯示「網路連線異常」，curl 打 API 卻正常CORS：這個網址的來源不在後端的允許清單（常見：有沒有 www）用 curl -H "Origin: …" 檢查，見網頁篇第 3 節
好幾張截圖長得一模一樣沒權限的頁面被導回別頁每次截圖印出 page.url 比對
每次執行都要重新登入SPA 的登入狀態不會留在新開的瀏覽器登入和截圖寫在同一次執行裡
截圖模糊預設 1 倍解析度device_scale_factor=2

5. 語音測試​

錯誤／現象原因處理
say 回傳成功但沒聲音AI 的沙盒拿不到桌面音訊say -o 產生檔案，再用 afplay 播放
afplay 也沒聲音輸出裝置不是喇叭、靜音查預設輸出裝置與音量，見語音篇第 4 節
「聆聽中」有出現，辨識結果是空的手機沒收到聲音靠近、調大聲、換更清楚的語音
開頭幾個字沒被辨識太早開始播放按住後等 1～1.5 秒再播
另一支 Android 手機用 file:// 播放音檔沒反應新版 Android 的儲存權限讓播放器讀不到改用電腦開 http 伺服器＋adb reverse，見語音篇 3.1
