申請 eu.org 免費網域教學

目標：免費拿到一個 yourname.eu.org 網域，並掛到 Cloudflare（或其他 DNS 商）管理。 適合：個人專案、自架服務、想要網域又不想花錢的人。 最後更新：2026-06。

0. 這是什麼 / 取捨​

  • eu.org：1996 年起的免費網域服務，志工營運。網域永久免費、不過期。
  • 代價：採人工審核，幾天～數週；名稱固定是 xxx.eu.org 形式。
  • 想要「今天就能用」或不想等審核，請改用付費網域（Cloudflare Registrar 成本價、Porkbun 等，.xyz 常 < 1 鎂/年）。

1. 先懂這幾個觀念（少踩雷的關鍵）​

  1. 要先有「能運作的 nameserver」才送申請。 eu.org 審核會去查你填的 NS 是否真的權威回應你的網域。 → 正確順序：先在 DNS 商（本教學用 Cloudflare）建好 zone → 再送 eu.org 申請。

  2. 直接註冊在 EU.ORG 底下，名字至少 4 個字。 3 字以下會被擋，錯誤訊息：('Domain length too short', ('EU.ORG', 4))。

  3. 網域名稱不是祕密。 一旦 Cloudflare 之類發 TLS 憑證，hostname 會進入公開的 Certificate Transparency log，全世界查得到。安全要靠認證、不靠名字保密 → 取中性、不洩漏身分的名字。

  4. whois 公開。 你在 eu.org 填的聯絡資料（email/地址）可能被公開查到 → 用專用 email、地址給最低限度（但別填明顯假資料，會被退）。

2. 需要準備​

  • 一個 DNS 商帳號（本教學用 Cloudflare，免費方案即可）。
  • 一個你會固定收信的 email（審核結果寄這）。

3. 步驟​

Step 0 — 想好名字​

  • ≥4 字、中性好記、好打（之後可能要在手機上打）。
  • 粗略確認沒被用：dig SOA yourname.eu.org（回 NXDOMAIN/查無 ≈ 可能可用）。 也可用任一線上 DNS 查詢網站。
  • ⚠️ DNS 查不到 ≠ 一定能註冊（短名、保留名仍可能被擋）；最終以 eu.org 送出時為準。

Step 1 — 先在 Cloudflare 建 zone、拿 nameserver（關鍵，先做）​

  1. Cloudflare 登入 → Add a site → 輸入完整網域 yourname.eu.org → 選 Free。
  2. 它掃描現有 DNS 記錄 → 全新網域 0 筆是正常的 → 繼續。 不用加任何 A / www / MX 記錄。
  3. 記下它配給你的 2 個 nameserver，例如： 
    xxxx.ns.cloudflare.com
    yyyy.ns.cloudflare.com
  4. 狀態會顯示 Pending（等你改 NS）——正常，先放著（我們的「registrar」是 eu.org，等下在那邊填）。

Step 1.5 — 驗證 NS 已權威回應（建議，省得審核卡關）​

送 eu.org 前，先確認 Cloudflare 那 2 台已經在權威回應你的網域：

dig +norec SOA yourname.eu.org @xxxx.ns.cloudflare.com
dig +norec NS  yourname.eu.org @xxxx.ns.cloudflare.com
  • 回應的 flags: 含 aa（authoritative），且 ANSWER SECTION 有 SOA / NS 記錄 → OK。
  • 沒有 dig 的話：用線上 DNS checker（搜尋 "DNS SOA lookup"），指定對 xxxx.ns.cloudflare.com 查 yourname.eu.org 即可。

Step 2 — 建立 eu.org 帳號（handle）​

  1. 開 https://nic.eu.org/arf/ → 註冊。
  2. 填聯絡資料：
    欄位說明
    E-mail必填、要能收信（審核結果寄這）
    Country必填（下拉選單）
    Address line 1通常必填，給最低限度即可
    Address 2–5 / Phone / Fax多半選填，可留空
    • ⚠️ whois 公開 → 用專用 email、少填可辨識資訊。
  3. Handle：你的帳號/聯絡代號，系統會自動接上固定後綴 -FREE（例如你打 leobox → handle 變 LEOBOX-FREE）。
    • 用中性代號、別用真名（它會是公開 whois 聯絡人）。
    • 設一個密碼並存好（之後登入管理用）。

Step 3 — 申請網域​

  1. 用 handle 登入 → 申請新 domain。
  2. Complete domain name：填完整名稱含外層 → yourname.eu.org
    • 不是只填 yourname。
    • 要跟 Step 1 在 Cloudflare 建的 zone 名稱一字不差地一致。
    • 不要選 "open domain"（會變成 yourname.別的.eu.org，跟你的 Cloudflare zone 對不上）。
  3. Nameservers：
    • Name1 = xxxx.ns.cloudflare.com
    • Name2 = yyyy.ns.cloudflare.com
    • 其餘 Name / 所有 IP 欄 全留空。
    • ⚠️ 不需要 glue：glue（IP）只有在「NS 本身就在你要註冊的網域底下」時才要；Cloudflare 的 NS 在 cloudflare.com 底下、能獨立解析，所以 IP 全空。
  4. 檢查等級：選最嚴格的 server names + replies on SOA + replies on NS (recommended)。
  5. 送出。

Step 4 — 看送出結果​

  • 成功會看到類似： 
    SOA from xxxx.ns.cloudflare.com ... serial ... 
    NS  from xxxx.ns.cloudflare.com ... ok
    No error, storing for validation...
    → 申請已收下、進入待審。
  • 若看到： 
    IGNORED: we already have pending request(s) for that domain.
    → 這不是錯誤。代表你已經有一筆待審請求在排隊（多半是重複按了送出）。別再送，等審核即可。

Step 5 — 等審核​

  • 人工審核，幾天～數週，結果寄 email（記得看垃圾信匣）。
  • 查進度：用 handle + 密碼登入 nic.eu.org/arf/。

Step 6 — 核准之後​

  • eu.org 把 NS 正式委派到 Cloudflare → Cloudflare 從 Pending 翻成 Active。
  • 確認委派生效： 
    dig NS yourname.eu.org      # 公開查詢開始回 Cloudflare 的 NS = 委派成功
  • 之後 DNS 都在 Cloudflare 管理。你可以無限免費開子網域（app.yourname.eu.org、dev.yourname.eu.org…），不必再去 eu.org 申請。

4. 常見問題 / 踩雷對照​

症狀原因 / 解法
Domain length too short, ('EU.ORG', 4)直接註冊在 EU.ORG 下名字要 ≥4 字，換個長一點的
NS 檢查失敗 / 一直退送出前沒先在 DNS 商建好 zone → 先做 Step 1 + 1.5
IGNORED: we already have pending request(s)已在排隊，別重送，等審核
DNS 查 NXDOMAIN 卻說不能註冊短名/保留名；DNS 不是最終依據，ARF 送出才算數
一個人能申請幾個？沒公布硬上限，採人工審、申請真正需要的即可。多數情況一個網域 + 子網域就夠
想保留很短的名字改成 短名.某open domain.eu.org（多一層），或乾脆買便宜網域

5. 安全小抄​

  • 名字中性、不洩漏身分（hostname 會進公開 CT log，藏不住）。
  • eu.org 聯絡資料用專用 email、最低限度資訊（whois 公開）。
  • 真正的存取安全要靠你掛在這網域上的服務的認證機制（例如 Cloudflare Access + MFA），不是靠網域名稱。
