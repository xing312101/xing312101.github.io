用 iPhone SSH App＋Tailscale，安全連回 Docker 容器裡的 CLI

常見的另一條路線是「手機零安裝、純瀏覽器」：Cloudflare Tunnel + Access + 容器內 ttyd（下稱瀏覽器方案）。 本篇走另一條路：願意在 iPhone 裝 app，換取端到端加密、端點隱形的更強安全性。 兩條路可以並存，甚至接的是同一個 tmux session（見 §6）。 最後更新：2026-07。

0. 為什麼是 Tailscale＋SSH（跟其他做法比）​

Tailscale＋SSH（本篇）Cloudflare Tunnel＋Access（瀏覽器方案）❌ 路由器開 port 給 sshd
inbound port無（兩端外撥＋NAT 穿透）無（外撥）要開，掃描器幾分鐘找到你
認證前的攻擊面≈0（WireGuard 對未認證封包靜默丟棄，端點隱形）Cloudflare 邊緣（他們的團隊顧）你的 sshd 直接裸露（想想 2024 的 regreSSHion）
端到端加密✅ 雙層（WireGuard＋SSH），無人可見內容❌ TLS 在 CF 邊緣終止（可信中間人）✅
手機端要裝 2 個 app純瀏覽器、零安裝要裝 app
新的命門Tailscale 的 SSO 帳號＋手機本身Cloudflare／IdP 帳號你的 sshd 設定品質

結論：第三種永遠不要做；前兩種都合格，本篇的純安全性略勝（真端到端、端點隱形），代價是裝 app 與金鑰管理。

1. 架構​

iPhone（SSH app）
   │  WireGuard（Tailscale：兩端各自外撥打洞，NAT/CGNAT 後也通；打不通就走 DERP 中繼）
   ▼
宿主的 sshd（只對 Tailscale 介面開放，LAN/WAN 都碰不到）
   │  docker exec
   ▼
容器內的 tmux ── claude / 你的 CLI（斷線不丟工作）
  • SSH 的目標是「宿主」，不是容器：容器完全不用改（不裝 sshd、不 rebuild、少一個常駐攻擊面），進容器就是一行 docker exec。
  • ⚠️ blast radius 認知：能 SSH 進宿主（或任何在 docker 群組的帳號）≈ 拿到宿主 root——尤其若容器還掛了 /var/run/docker.sock（DooD）。這條通道要用「root 門」的標準對待。

2. iPhone 要裝哪些 App​

必裝：Tailscale（官方 app，個人方案免費）​

用 SSO 登入（Google / Apple / GitHub / Microsoft）——這個帳號從此是你的命門，務必開 2FA，最好用 passkey。

SSH client 三選一​

App私鑰安全mosh價格短評
Blink Shell（首選）✅ 可產生 Secure Enclave 金鑰——私鑰在手機安全晶片內生成、物理上不可匯出；支援 Face ID 鎖✅付費開源、終端與鍵盤體驗最好，工程師取向
Termius金鑰本機保存；⚠️ 別用雲端同步金鑰（免費版本來就不含同步——反而安全）❌免費夠用上手最快、介面最友善
Prompt 3（Panic）iOS 鑰匙圈❌付費老牌穩定、UI 精緻

挑選原則：私鑰能不能不離開手機（Secure Enclave ＞ 鑰匙圈 ＞ 可匯出的檔案）、有沒有生物辨識鎖、要不要 mosh。 避雷：來路不明的免費 SSH app（廣告 SDK、資料蒐集），以及任何要你把私鑰貼進網頁或上傳雲端的工具。

3. 步驟​

Step 1 — 宿主裝 Tailscale​

  • macOS：App Store 或 brew install --cask tailscale，登入你的 tailnet。
  • Linux：curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up
  • 這台是「伺服器」：到 Tailscale 後台（admin console）把它的 key expiry 關掉——不然幾個月後憑證到期、人在外面就連不回來。

Step 2 — 宿主開 sshd（只對 Tailscale 開）​

  • macOS：系統設定 → 一般 → 共享 → 遠端登入，勾「僅允許這些使用者」選你自己。
  • Linux：sudo apt install openssh-server
  • 硬化（/etc/ssh/sshd_config 或 sshd_config.d/ 覆寫檔）： 
    PasswordAuthentication no
    KbdInteractiveAuthentication no
    AllowUsers <你的帳號>
  • 確保 sshd 不暴露在 Tailscale 之外：路由器本來就不開 port（WAN 碰不到）；Linux 再用防火牆只放行 Tailscale 介面（若你也需要從 LAN ssh，先補上對應 allow 再套用）： 
    sudo ufw default deny incoming
    sudo ufw allow in on tailscale0 to any port 22 proto tcp
    （macOS 的遠端登入在家用 LAN 內仍可達，屬可接受的取捨。）

Step 3 — iPhone 設定​

  1. Tailscale app：登入同一個 tailnet → 開 VPN（設定裡開 On-Demand，免得每次手動開）。
  2. SSH app（以 Blink 為例）：config → Keys → ＋ → 選 Secure Enclave 產生金鑰 → 複製公鑰。
  3. 公鑰放到宿主 ~/.ssh/authorized_keys（加一行）。確認金鑰能登入後，才關密碼登入。

Step 4 — 連線：一行直達容器內的 tmux​

Tailscale 預設開 MagicDNS，用主機名即可（tailscale status 看得到）：

ssh -t <user>@<宿主的tailscale主機名> 'docker exec -it <容器名> tmux new -A -s claude claude'
  • -t：配置終端（tmux 需要）。
  • tmux new -A -s claude：附掛或建立同名 session——跟瀏覽器方案（ttyd）接的是同一個，手機 SSH／手機瀏覽器／桌機三處無縫接續。
  • 在 Blink/Termius 把整行存成該 host 的預設指令，之後點一下就進來。

🔒 進階：想讓「這把鑰匙只能進容器終端、拿不到宿主 shell」，在 authorized_keys 該行最前面加選項：

restrict,pty,command="docker exec -it <容器名> tmux new -A -s claude claude" <金鑰類型> AAAA...

⚠️ 但若容器本身掛了 /var/run/docker.sock（DooD），這道限制擋不住——容器內仍可指揮宿主 docker，等效宿主 root。

Step 5 —（可選）mosh：換網秒回​

Tailscale IP 在 WiFi↔5G 切換時不變，一般 ssh 多半撐得過短暫斷線；mosh 再加碼「秒速回到畫面、長時間背景不斷」：

  • 宿主：brew install mosh ／ sudo apt install mosh
  • Blink 把該 host 的連線方式改成 mosh 即可（Termius / Prompt 不支援 mosh）。

Step 6 —（可選，Linux 宿主限定）Tailscale SSH：連金鑰都不用管​

sudo tailscale up --ssh

SSH 認證整個交給 Tailscale 身分（誰能連誰由後台 ACL 控制），手機端不需要產生／保管金鑰，Step 2 的金鑰設定與 Step 3-2/3-3 全免。macOS 目前不能當 Tailscale SSH「伺服器」，mac 宿主走傳統 sshd 即可。

4. 安全檢查表​

  • 路由器沒有任何 port forwarding；sshd 對 WAN 不可達。
  • PasswordAuthentication no（只收金鑰）。
  • 私鑰在 Secure Enclave，或至少有強 passphrase＋生物辨識鎖。
  • 手機遺失 SOP：Tailscale 後台移除該裝置 ＋ 宿主 authorized_keys 刪該公鑰。
  • Tailscale 的 SSO 帳號開 2FA／passkey；定期看後台裝置清單有無陌生裝置。
  • 知道個人 tailnet 預設 ACL 是「網內互通」——裝置變多後記得收斂（只允許 手機 → 宿主:22）。
  • 伺服器節點關 key expiry；手機節點保留到期（定期重新認證是好事）。
  • 認知：這條通道 ≈ 宿主 root 門（docker 群組、DooD）。

5. 疑難排解​

症狀原因／解法
連不上兩端 Tailscale 都開了？同一個 tailnet？宿主 tailscale status 看手機在不在線上
連得上但延遲高NAT 太嚴打洞失敗、走 DERP 中繼（仍是端到端加密，只是繞路）；換個網路環境常會恢復直連
切回 app 發現斷線iOS 背景限制，正常。tmux 保住工作現場，重連即回；要「秒回」用 mosh（Step 5）
家裡是 CGNAT／動態 IP完全無所謂——兩端都是外撥，不需要公網 IP，也不用 DDNS
改了 sshd 設定沒生效macOS：取消再重新勾選「遠端登入」；Linux：sudo systemctl restart sshd

6. 與瀏覽器方案並存（建議的最終形態）​

兩條路互不干擾，而且都約定 tmux new -A -s claude → 接的是同一個工作現場：

情境走哪條
自己的 iPhone、日常使用Tailscale＋SSH（本篇）：最強安全、終端體驗好
臨時借用的裝置、只有瀏覽器Cloudflare Tunnel＋Access（瀏覽器方案）：零安裝，用完關門

平常把 Cloudflare 那扇門關著（docker compose stop cloudflared）當備援，遠端入口只留 Tailscale——攻擊面最小。
