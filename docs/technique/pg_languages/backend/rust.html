Rust 環境安裝與 Toolchain 管理

1. 安裝 Rust（官方推薦）​

Linux / macOS​

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

重新載入 shell：

source $HOME/.cargo/env

確認安裝：

rustc --version
cargo --version
rustup --version

2. Rust 核心工具

工具用途
rustcRust 編譯器
cargo套件管理與 build tool
rustuptoolchain 管理器

3. Toolchain 管理

查看目前 toolchain：

rustup show

查看已安裝版本：

rustup toolchain list

安裝 stable​

rustup toolchain install stable

安裝 nightly​

rustup toolchain install nightly

安裝指定版本​

rustup toolchain install 1.77.2

4. 切換 Toolchain

全域切換​

切換 stable：

rustup default stable

切換 nightly：

rustup default nightly

專案內切換（推薦）​

cd my-project
rustup override set nightly

查看 override：

rustup override list

取消 override：

rustup override unset

5. 固定專案 Rust 版本（推薦）

建立：

rust-toolchain.toml

內容：

[toolchain]
channel = "1.77.2"
components = ["rustfmt", "clippy"]

或：

[toolchain]
channel = "stable"

用途：

  • 團隊統一 Rust 版本
  • CI/CD 一致
  • 避免版本差異

6. 建立 Rust 專案

cargo new myapp
cd myapp

專案結構：

myapp/
├── Cargo.toml
├── Cargo.lock
└── src/
    └── main.rs

7. Cargo 依賴管理

Cargo.toml​

[dependencies]
tokio = "1"
serde = "1"

Cargo.lock​

鎖定實際依賴版本。

建議：

專案類型是否 commit Cargo.lock
ApplicationYes
LibraryUsually No

8. 常用 Cargo 指令

編譯​

cargo build

Release 編譯​

cargo build --release

執行​

cargo run

測試​

cargo test

檢查​

cargo check

9. rustfmt（格式化）

安裝：

rustup component add rustfmt

使用：

cargo fmt

檢查格式：

cargo fmt --check

10. clippy（Lint）

安裝：

rustup component add clippy

使用：

cargo clippy

嚴格模式：

cargo clippy -- -D warnings

11. 更新 Rust

更新所有 toolchain：

rustup update

更新 stable：

rustup update stable

12. 移除 Toolchain

rustup toolchain uninstall nightly

13. Cross Compile

安裝 target：

rustup target add aarch64-unknown-linux-gnu

查看所有 target：

rustc --print target-list

14. VSCode 開發環境

VSCode：

https://code.visualstudio.com/

rust-analyzer：

https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer

15. 建議實務配置

rust-toolchain.toml​

[toolchain]
channel = "stable"
components = ["rustfmt", "clippy"]

CI​

cargo fmt --check
cargo clippy -- -D warnings
cargo test

16. 新手推薦流程

安裝 Rust​

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

建立專案​

cargo new demo
cd demo

建立 rust-toolchain.toml​

[toolchain]
channel = "stable"
components = ["rustfmt", "clippy"]

開始開發​

cargo run
